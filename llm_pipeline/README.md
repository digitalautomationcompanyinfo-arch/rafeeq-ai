# AI Startup MVP: 13B+ Model Fine-Tuning Pipeline

## المشكلة
العديد من مشاريع الذكاء الاصطناعي تتطلب بناء نماذج لغوية كبيرة مخصصة (Fine-tuned LLMs) بتكلفة منخفضة وتكون جاهزة للاستخدام التجاري. التحدي الأساسي هو تدريب نماذج بحجم 13B+ بارامتر على بيئات حوسبة محدودة (مثل Google Colab المجاني) دون فقدان البيانات بسبب انقطاع الجلسات، مع الحفاظ على مرونة نقل المشروع بين مزودي الحوسبة السحابية.

## الحل
يوفر هذا المشروع هيكلة متكاملة (Pipeline) لتجهيز البيانات وتدريب نموذج مفتوح المصدر (مثل Qwen 2.5 14B أو Llama 2 13B) باستخدام تقنية **QLoRA (4-bit quantization)** لتقليل استهلاك الذاكرة بشكل كبير ليناسب بطاقات T4/L4. يعتمد الحل على:
- استخدام Google Drive لتخزين البيانات الخام والمُعالجة ونقاط الحفظ (Checkpoints) لتفادي قيود وقت جلسات Colab.
- استخدام ضغط البيانات (tar.gz) لتقليل حجم النقل.
- الاستقلالية عن أي مزود سحابي محدد، مما يتيح نقل البيانات والتدريب إلى AWS S3 أو Nebius AI لاحقاً.

## طريقة التشغيل (المرحلة 1 و 2)

### 1. تجهيز البيئة
قم بتثبيت المتطلبات:
\`\`\`bash
pip install -r requirements.txt
\`\`\`

### 2. تجهيز البيانات
ضع بياناتك الخام (بصيغة `dataset.jsonl` أو `dataset.csv`) في مجلد `data/raw/`، ثم قم بتشغيل سكربت التنظيف والتقسيم:
\`\`\`bash
cd scripts
python 02_data_prep.py
\`\`\`
سيقوم السكربت بإنشاء ملفات `train.jsonl`، `val.jsonl`، و `test.jsonl` في مجلد `data/processed/`.

### 3. المزامنة مع Google Drive
لرفع البيانات المعالجة إلى Google Drive:
\`\`\`bash
python 01_gdrive_sync.py
\`\`\`
*ملاحظة: سيُطلب منك المصادقة مع حساب Google في المرة الأولى، وسيتم حفظ الاعتمادات في `mycreds.txt`.*

### 4. التدريب (Baseline)
يمكنك رفع مجلد `llm_pipeline` بالكامل إلى Google Colab وتشغيل التدريب:
\`\`\`bash
python 03_train_qlora.py
\`\`\`
يقوم هذا السكربت بتدريب نموذج Qwen 2.5 14B (قابل للاستخدام التجاري - Apache 2.0) باستخدام QLoRA، ويحفظ نقاط الحفظ كل 50 خطوة (أو بعد كل Epoch) في `models/checkpoints/` بحيث يمكن مزامنتها مع Drive لتجنب ضياع العمل عند إعادة تعيين جلسة Colab (12 ساعة).

## النتائج الأولية والخطوات القادمة
- **المرحلة 1 و 2 مكتملة**: تم إعداد هيكل المشروع، ربط التخزين، تجهيز البيانات، وإعداد سكربت التدريب الأولي.
- **المرحلة 3 (واجهات العرض والتقييم)**: سيتم البدء بها لاحقاً بعد التحقق من نجاح التدريب الأولي واستقرار الأداء على عينة مصغرة من البيانات (Proof of Concept).
- **ملاحظات هامة للتدريب**: نظراً لأن نماذج 13B+ قد تواجه قيوداً في الذاكرة (OOM) حتى مع QLoRA على بيئة Colab المجانية (T4 15GB)، يُنصح بتقليل `batch_size` و `max_seq_length` إلى الحد الأدنى، أو استخدام نموذج مثل Mistral Nemo 12B، أو تجربة التدريب أولاً على نموذج 7B للتأكد من خلو الـ Pipeline من الأخطاء قبل الانتقال إلى 13B+.
